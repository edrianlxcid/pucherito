# pucherito

Un pequeño juego de plataformas en el navegador: un errante con su farol cruza tres fases
(Las Cavernas Dormidas, El Jardín de Esporas y La Ciudad bajo la Lluvia) con música de fondo
y subtítulos, hasta llegar a un poema escrito en una hoja de cuaderno.

- `index.html`: el juego completo (se personaliza en `CONFIG`, al inicio del script)
- `subtitulos.js`: letra sincronizada y traducciones propias (opcional)
- `sincronizar.html`: herramienta para sincronizar la letra a mano

Se publica tal cual con GitHub Pages (rama `main`, carpeta raíz).
